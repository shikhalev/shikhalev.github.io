## Описание

> Легкая ветровка с ярким принтом, который наносится по всей поверхности. Можно сделать со своим дизайном.
>
> Правила ухода
>
> : стирать при температуре не выше 30 градусов, без отбеливателя. Гладить при температуре не выше 110 градусов
>
> Тип нанесения
>
> : сублимация на ткани
>
> Детали
>
> : подол и капюшон оформлены резинкой с фиксаторами, по бокам два кармана без застежек.
>
> Состав
>
> : 100% полиэстер
>
> Сезон
>
> : демисезон
>
