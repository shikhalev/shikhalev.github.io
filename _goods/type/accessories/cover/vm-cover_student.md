## Описание

> Обложка для студенческого билета из натуральной кожи. Внутри прозрачные пластиковые крепления. На выбор — 10 цветов
> внутреннего покрытия. Можно сделать со своим дизайном.
>
> Детали
>
> : размер — 11*8 см. Печать на всей внешней стороне
>
> Состав
>
> : натуральная кожа
>
> Тип нанесения
>
> : ультрафиолетовая печать
>
> Правила ухода
>
> : Аккуратно протирать влажной тканью. Нельзя использовать абразивные материалы для чистки (металлические щетки и т.п.).
>
