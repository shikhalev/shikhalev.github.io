## Описание

> Обложка для паспорта сделана из натуральной матовой кожи с бархатистой внутренней поверхностью. Листы фиксируются прозрачными пластиковыми креплениями.
>
> Детали
>
> : размер 19,3 х 13,7 см; прозрачные пластиковые крепления
>
> Состав
>
> : натуральная матовая кожа
>
> Правила ухода
>
> : аккуратно протирать влажной тканью, нельзя использовать абразивные материалы для чистки (металлические щетки и т.п.)
>
> Тип нанесения
>
> : ультрафиолетовая печать
>
