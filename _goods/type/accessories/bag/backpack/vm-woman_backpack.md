## Описание

> Стильная, компактная сумка-рюкзак из плотного текстиля с несколькими карманами, чтобы удобно разложить
> все необходимое. Небольшой, но вместительный: поместится ноутбук с 13-дюймовым экраном.
>
> Узкие лямки из стропы с регулируемой длиной. Сверху 2 ручки из стропы, соединенные хлястиком на кнопке,
> чтобы рюкзак нести как сумку. Основное отделение закрывается на молнию с двумя бегунками. Спереди накладной
> карман с клапаном на молнии. На внутренней части спинки имеется карман на молнии для документов. Боковые карманы
> без подкладки, со складками по низу для объема, в них поместится маленькая бутылочка.
