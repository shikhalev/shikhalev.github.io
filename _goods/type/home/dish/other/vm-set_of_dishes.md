## Описание

> Кружка изготовлена из вы­со­ко­ка­чес­т­вен­ной белой керамики. Тарелка изготовлена из фар­фо­ра.
> Принт наносится на бо­ка кружки: два изображения или только с од­ной стороны.
> На та­рел­ку принт наносится на плос­кую часть.
>
> Тип нанесения
>
> : Сублимация.
>
> Правила ухода
>
> : Мыть руками, нельзя мыть в по­су­до­мо­е­ч­ной машине и использовать абразивные материалы для чис­т­ки (металлические щетки и т.п.).
>
> Детали
>
> : Кружка: объем — 330 мл, ди­а­метр — 80 мм. Принт наносится на бо­ка кружки, можно сделать два разных изображения.
>
>   Тарелка: диаметр — 210 мм, диаметр для на­не­се­ния прин­та — 120 мм.
>
> Состав
>
> : Керамика.
>
