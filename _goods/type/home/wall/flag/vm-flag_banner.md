## Описание

> Флаг-баннер пригодится для ук­ра­ше­ния помещений и балконов в честь праздников, а также для офор­м­ле­ния уличных
> мероприятий. Принт наносится с од­ной стороны по всей поверхности.
>
> Состав
>
> : 100% полиэстер.
>
> Тип нанесения
>
> : Сублимация на тка­ни.
>
> Правила ухода
>
> : Стирать при тем­пе­ра­ту­ре не вы­ше 40 гра­ду­сов, без от­бе­ли­ва­те­ля. Гладить при тем­пе­ра­ту­ре не вы­ше 110 градусов.
>
> Детали
>
> : Размер 67×109 см, плотность ткани — 160–180 г/м²; по кра­ям флага есть четыре люверса для крепления.
>
