Компоновка всех представлений darktable похожа и состоит из центральной области и панелей по краям:

![screen-layout](_src/tr/darktable-manual/overview/user-interface/screen-layout/screen-layout.png){: width="900" }

1. центральная область
: Содержит информацию и функции, относящиеся к текущему представлению.

2. левая панель
: Содержит модули, предназначенные преимущественно для отображения информации.

3. правая панель
: Содержит модули, предназначенные преимущественно для обработки снимков.

4. верхний баннер
: Содержит информацию о текущей версии darktable и позволяет переключаться между представлениями. Также используется некоторыми модулями для отображения дополнительных подсказок и сообщений.

5. [верхняя панель](../top-panel/)
: Предоставляет доступ к глобальным настройкам и сочетаниям клавиш.

6. [нижняя панель](../bottom-panel/)
: Предоставляет доступ преимущественно к настройкам и сочетаниям клавиш, относящимся к текущему представлению.

7. [панель фотоплёнки](../../../module-reference/utility-modules/shared/filmstrip/)/[таймлайна](../../../module-reference/utility-modules/lighttable/timeline/)
: Необязательная панель, которую можно включить в нижней части экрана для отображения таймлайна (в представлении lighttable) или фотоплёнки (в других представлениях) снимков из текущей коллекции.

См. компоновку экрана, специфичную для [представления lighttable](../../../lighttable/lighttable-view-layout/) или [представления darkroom](../../../darkroom/darkroom-view-layout/).

## Размер и видимость панелей

Размер левой, правой панелей и панелей фотоплёнки/таймлайна можно изменять, перетаскивая их внутренние границы.

Каждую из панелей можно развернуть или свернуть, нажав на треугольник у внешнего края панели. Видимость панелей также можно изменять с помощью следующих сочетаний клавиш:

 - `TAB` временно расширяет центральную область на всё окно. Нажмите ещё раз, чтобы вернуться к предыдущему виду.
 - `F11` переключает полноэкранный режим
 - `Shift+Ctrl+t` переключает верхнюю панель (между изображением и верхним баннером)
 - `Shift+Ctrl+b` переключает нижнюю панель (между изображением и фотоплёнкой/таймлайном, если они отображаются)
 - `Shift+Ctrl+l` переключает левую панель
 - `Shift+Ctrl+r` переключает правую панель
 - `Ctrl+f` переключает фотоплёнку/таймлайн
 - `Ctrl+h` переключает верхний баннер
 - `b` переключает отображение всех границ и элементов сворачивания панелей

---

**Примечание:** Размер и видимость панелей сохраняются независимо для каждого представления.
